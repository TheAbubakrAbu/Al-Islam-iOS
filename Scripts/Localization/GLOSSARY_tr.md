# Turkish (tr): as Apple's Turkish iOS and the Diyanet write it

Address the reader with the polite "siz" (Dokunun, Seçin, Açın), warm and clear; buttons short as Apple's
(Paylaş, Sil, Kopyala). Correct Turkish letters always: ç ğ ı İ ö ş ü (and the circumflex where Diyanet usage
keeps it: Kur'ân optional, "zekât", "Kâbe"). Title Case for titles and buttons as Apple's Turkish does.

**Suffixes on placeholders:** Turkish attaches case endings to nouns, but `%@` can be any word, so the
right vowel cannot be known. Never write "%@'de", "%@'nin" etc. Rephrase: "Konum: %@", "%@ için", a
construction with "adlı", or put the placeholder where no ending is needed. Same for numbers: write
"%lld ayet", not "%lld'inci".

**Word order:** Turkish puts the name before the noun: "Surah %@" is "%@ Suresi", "Juz %lld" is
"%lld. Cüz", "Hadith %@" is "%@. Hadis" only when %@ is a number (otherwise "Hadis %@").
