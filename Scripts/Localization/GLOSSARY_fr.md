# French (fr): as Apple's French iOS and French-speaking Muslims write it

For Muslims in France, Belgium, Switzerland, Quebec, North and West Africa: standard French, neutral (no
regionalisms). Address the reader with "vous" (Touchez, Choisissez, Activez), warm and clear; buttons short as
Apple's (Partager, Supprimer, Copier). Sentence case for titles and buttons ("Ajouter aux favoris").

**Typography:** a no-break space (U+00A0) before : ; ? ! and inside « guillemets » (« … »), and before %
("50 %": "%lld %%" with U+00A0). Apostrophe: the typographic ’ in prose is fine; keep the key's own quotes
where it quotes a label. Accented capitals in ALL CAPS headers (É, À).

**Placeholders and gender:** `%@` can be any word, so avoid an article that must agree with it ("le %@");
rephrase ("Sourate : %@", "%@ téléchargé" only when %@ is always masculine). Elision: never "de %@" before a
vowel-initial name if you can avoid it ("Récitation par %@").
